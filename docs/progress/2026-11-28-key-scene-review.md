# EXP-10 · 关键幕集中审片

整期精修前集中审查所有关键幕，按成片顺序提供连播与逐幕定位，每幕提供标注构图和真实粗动态。首版稿件和配音由制作技能负责。用户自行安排审片时间，可在一轮会话中陆续反馈。针对当前版本明确通过后，制作端按适用范围直接继续。

流程使用[制作入口](../../skills/news-to-video/references/production-baseline.md)和[集中审片模板](../../skills/news-to-video/references/editorial-handoff.md#关键幕集中审片)。行为用例 121–122 覆盖关键幕的完整性、反馈版本、按指令放行和只重审实质变化的镜头。

本机 191 项、公开版 196 项既有 Python 回归通过，技能格式、链接和两侧审片规范一致性通过。用例 121–122 是新增行为规格。真实新一期的集中审片与人工确认待实际节目执行。

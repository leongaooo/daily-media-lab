# EXP-10 · 关键幕集中审片

整期精修前集中审查所有关键幕的视觉呈现。按成片顺序提供连播与逐幕定位，每幕提供标注构图和可播放的粗动态。配音尚未制作时，可按脚本节奏和预计时长静音送审。用户自行安排审片时间，可在同一会话陆续反馈。当前版本获准后，视觉精修与正式配音并行。已有冻结口播直接复用，技能用实测 cue 对齐镜头、动作、字幕和尾音，并自行核验配音和声画质量。

流程使用[制作入口](../../skills/news-to-video/references/production-baseline.md)和[集中审片模板](../../skills/news-to-video/references/editorial-handoff.md#关键幕集中审片)。行为用例 121–124 覆盖静音送审、版本反馈、放行、并行制作及冻结原声复用。`episode.py` 的有声预演回执仍依赖 `audio_locked` 和 `visual_ready`，新增回归验证缺少冻结音频时不会误登记该回执。

本机 192 项、公开版 197 项 Python 回归通过。四条行为演练对照上轮公开基线，覆盖静音送审、同一会话累计反馈、放行后并行制作、冻结口播复用及技术回执。另用合成素材将三幕编码为连续 72 帧，完整解码并确认只有视频流和幕序正确。冻结音频测试复用原始 WAV 和 cue，核对实测帧边界覆盖尾音，源文件哈希一致。 真实节目的集中审片、正式配音和感知验收待实际制作。

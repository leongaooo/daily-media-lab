## 维护者验收与公开复建 · 2026-11-27

- 维护者明确验收了本机重新制作的卡亚尼样片。公开仓库提供可编辑混合分镜示例和通用加载修复，示例通过 `qwen-uncle-fu-v1` 生成自己的口播。
- Windows 加载 Qwen 时，safetensors 的内存映射切片会触发原生访问冲突。本批在 `qwen_synth.py` 的模型加载阶段使用显式读取，加载完后沿用 CUDA 推理。相关代码位于 `qwen_weights.py`，Windows 的依赖清单固定 safetensors 0.8.0。
- 从独立 Git 检出创建新的公开运行配置，用公开示例的文稿生成全部 8 句，再由实际 cue 排定画面。按[示例命令](../../examples/idc-kajaani/README.md)运行 Blender、SVG、封存与两版合成。两版均为 1,081 帧、45.042 秒，完整解码通过。正式 SRT 的 8 条字幕和 14 个编码位置通过核对。
- 两版在 Edge 以 1× 播到末帧，带声版报告 0 掉帧，静音版报告 3 掉帧。公开检出 174 项自动回归通过。本次公开复建使用同一台 Windows 机器的现有工具，独立机器安装与设备试听待验证。

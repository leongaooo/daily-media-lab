# EXP-05 · 精炼成果固化与定向公开同步

范围：落实已获用户一般认可的短段制作方法、代码防护及复用入口。用户明确不需要制作整片，随后明确本机与开源副本同步，并要求主要推送远端。本批不制作新媒体，不提交私人声音、有声样片、原始新闻PDF、密钥、runtime或模型。

## 交付行为

- 修复旧图解字段丢失：`nodes/source/summary`兼容到`editorial_nodes/data_source/editorial_summary`。节点冲突拒绝，来源／摘要优先级差异写入生成载荷。
- 生产前拦截空对照、空检查板、被空shot覆盖的内容；对照严格两项，检查板一至四项。实际组件展示全部条目，focus只强调；两项互补标准不再默认标成前后变化。
- `review_window.py`按整数样本区间提取冻结单声道干声，保持解码PCM并另记母版／窗口身份，拒绝覆盖源及既有目标。不调用TTS或重采样；DOUBLE输出不表示下游读取链具有同样精度。
- 项目级`editorial.render`支持本次子进程的并发、顺序编码、FFmpeg线程和Node堆设置。省略时保持原默认，非法类型／范围拒绝。资源恢复经验有适用条件，不归因所有原生编码错误。
- `references/refinement-workflow.md`固化素材内容角色、语义字幕、实际消费者及五类验收证据。一般赞许只记对应样片方向，不能推定耳机／扬声器、声音细项、整期或跨题材认可。明确“不制作整片”优先。

```powershell
python -X utf8 -m unittest discover -s scripts -p 'test_*.py'
```

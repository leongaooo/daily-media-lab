# Web3 一期多板块工程示例

来自 2026-11-11 实际 Editorial 制作，含六幕、两个独立资讯板块。`project.json` 保留口播、证据 ID、素材 ID 与来源；绑定图片随示例存放。

这是历史制作样例，本次没有重新核验其中资讯、协议状态或链上数据。原工程的旧版布局字段已在本副本删除，当前画幅为 Editorial 1920×1080 / 24 fps；未改原始制作目录。

当前配音仍要求匹配私有 B 环境，本示例不包含声音参考或权重。可以先阅读剧本/JSON、检查图文交接；完整重渲染需按[环境说明](../../docs/GETTING_STARTED.md)准备条件。

预览见[成果区](../../previews/README.md)。生成图为概念示意，不是现场实拍或真实产品截图；公开分发范围随正式发布一并核实。

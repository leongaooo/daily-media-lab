## 画面

[播放/下载静音短片](editorial-silent.mp4) · [查看六幕画面](contact-sheet.jpg)

这份样片来自 2026-11-11 的实际 Web3 日报制作：Privacy Rings 与 Fort Canning 两个内容板块，一期一片。原片约 93 秒，1920×1080 / 24 fps。这里抽取每幕 3 秒做静音选集，GIF 为低帧率缩略预览，不代表成片帧率。

请观察图片与图解如何承担不同任务：示意图片建立对象与环境，图形表达可见性边界、阶段与检查关系，字幕在独立底部区域连续出现。样片只展示当时制作结果，本次没有重新核验新闻时效或链上状态。

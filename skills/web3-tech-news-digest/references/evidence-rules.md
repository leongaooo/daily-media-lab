# Web3专业证据规则

以下是逐条核验工具，不是要求向读者逐项展示的固定栏目。重要结论优先两类互补证据：维护方原始规范/发布与实际部署、独立研究或项目复盘。材料不足时缩小结论，不为满足双来源形式重复引用同稿。

## 1. 提案、治理与部署

- 记录chain/network、proposal_id、规范状态、实现版本、测试网络和激活条件；按项目原生流程记录，不强行套统一状态机。
- EIP的Final描述标准成熟度，不表示网络已部署；ERC接口标准不保证钱包或合约实现。客户端Release、多个客户端兼容、测试网激活和主网激活分别找证据。
- 治理讨论、投票通过、时间锁排队、链上执行分别核验提案/交易；宣布投票不等于通过，通过不等于执行。提案页面的更新时间不当作投票或执行时间。
- 公布升级高度、epoch或UTC时间仍是计划，除非有激活确认。保留依赖、延期和已知未决问题；不从日期倒推出已完成。

## 2. 合约、语言与工具

- 核对仓库/包名、tag、commit（有则保留）、发布时间、stable/prerelease/nightly、目标平台及网络。GitHub已验证提交签名不等于项目安全或无恶意代码。
- 变更说明是维护方声明；breaking change即使置于patch release仍须报道其实际兼容性，不凭版本号推断无风险。找迁移文档、PR及回归范围。
- 将变更映射回读者项目时，明确核对依赖清单/锁文件实际版本、直接和传递依赖、受影响调用及配置；不要只说“看迁移文档”或从公告版本推断项目已使用。没有检查真实项目时将这些写成待执行动作，不能声称已完成适配。
- 编译器问题记录受影响版本区间、优化器、viaIR/后端、EVM目标、触发条件与修复版。没有穷尽核验时不要声称所有合约受影响或此前版本都安全。
- 合约记录链、地址、代理/实现、升级管理员、源代码和部署版本（仅在结论依赖时查）。某部署审计不覆盖同名fork、后续升级或全部依赖；verified source只说明源码验证，不等于审计。
- 形式化验证说明模型、性质与假设，不推出整体绝对安全。新闻建议使用具体检查问题，不直接替代生产迁移方案。

## 3. 吞吐、最终性与费用

- TPS核对提交/成功/最终确认、交易种类、批处理、投票/非投票、主网/测试网/本地、负载持续时间、硬件和网络条件。合成峰值不等于持续业务吞吐。
- 延迟区分出块、软确认、经济最终性、提现等待；不同信任假设下不能只比一个毫秒数。
- 费用注明链、时点、币种/法币换算、交易类型、执行/数据可用性/证明/桥接或提现成本。费用降低不能在缺方法时推出总成本降低或所有DApp同等受益。
- 厂商或项目自测写“该团队测试显示”，保留方法缺口。独立结论需要独立来源和可比口径，不做缺条件的排名。

## 4. L2、跨链与ZK

- 分清执行、结算、数据可用性、排序器、证明系统、验证者/委员会、管理员和升级权限；链名不自动说明安全继承。
- zk、有效性证明和零知识隐私不是同义词；EVM兼容与等价、去中心化证明与去中心化排序不能互推。
- 核对状态证明、欺诈证明的实际启用范围、退出路径、挑战窗口、紧急暂停与升级时间锁。按公开事实描述，不从“L2”标签推断无许可退出。
- 跨链桥核对源/目标链、验证方式、信任主体、可升级性和事件状态。图解只呈现已证实关系。

## 5. 行业采用与业务指标

- 核对用户地区、资格、灰度/公开可用、支持设备/钱包/链、托管与接入要求。签约、原型、PoC、测试上线、商用与使用规模分别写。
- TVL、TVS、供应量、交易量、净流入、收入、地址数和用户数分别保留原指标；说明时间窗、样本、数据提供者、计算方法、价格变化、激励及重复计算风险。缺方法不合成市场份额。
- 活跃地址不直接当人，交易量不直接当收入；代币涨价导致的法币指标增长不等于净流入。链上存在不证明线下资产权属和兑付。
- 稳定币和RWA核对发行主体、兑付资格及适用地区；相关政策找发布机关和原始文本。新闻说明可用性与技术条件，不改写成投资建议。

## 6. 安全事件与事故

- 区分疑似、项目确认、攻击路径确认、受影响范围、暂停/缓解/补丁/恢复；跨时区核对时间。仅社交截图或匿名归因不当已确认事实。
- 损失、转移金额、冻结和追回分别统计，避免多链转移重复计数；没有最终结算就写估计及出处。链上交易支持交易发生，不单独证明攻击者身份或法律责任。
- 引用复盘核对是否由受影响方、安全研究者或服务商发布，披露范围与利益关系。源码、审计和追偿进度不推出事件已完全结束。
- 行动聚焦版本、权限、配置、受影响资产及公告要求的检查，不凭新闻推测生产紧急操作，也不生成未经验证的利用流程。

## 7. 政策与来源关系

- 标明司法辖区、发布机关、原文、草案/正式/生效/过渡期、适用主体和限制，不把某地区政策扩成全球规则。
- 维护方发布、审计方分析、客户案例、独立研究、社区意见和编辑推断分别归属。共同作者、资助关系、联合稿及转载不算独立重复确认。
- 有方法说明的独立研究优于无证据评论；社区意见只能证明其观点存在。没有样本和抽样框不推断共识或量化好评率。

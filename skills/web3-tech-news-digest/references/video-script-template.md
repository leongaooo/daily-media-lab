# 要闻剧本交付模板

每期使用一份剧本、一个连续节目结构，默认交接一个制作项目和一个成片。多条新闻在同一剧本内设置独立内容板块，分别保留核心问题、幕号及证据；不要求新闻具有共同问题，不强造因果。只有用户明确要求分集或单条独立视频才拆片。不为凑时长拆出空幕，不附重复的全文演播稿。

## 视频定位

- 标题：直接呈现实质变化，限制词保留在标题或开场。
- 观众、核心问题、统计截止时间/时区。
- 新闻窗口：48小时；必要的“本周补充”逐项标原始日期；历史背景单列。
- 预计总时长：依据口播估计，未实测。不是最终SRT时间线。

## 分幕

### S01｜本幕目的｜预计时长

**口播**：自然短句，保留影响判断的发布主体、阶段、网络/版本、地区和证据局限。必要时附缩写/版本的读法；可分别记录字幕原文text和朗读spoken，但二者不能语义不同。

**屏幕文字**：仅本幕需要的标题、关键数值或条件，精确字符串由后期合成。

**视觉与资产**：在生成示意、经核实真实素材、复用、原创SVG/图表、主题文字中明确选择；给asset_id和对应事实。无需生图时说明原因。证据：E01/E02。

如选原创图解，写节点/箭头/条件/图例及证据，保留SVG源并由制作技能转PNG；避免未经证实的链间、权限或资金关系。

## 图片生成单（选生图时逐张必填）

### A01｜生成1张[明确主体和场景]的图片

- 用途：对应幕号、资讯点、主体数量/动作/环境。没有数量证据时只作通用概念，不能暗示某真实部署。
- 构图：遵循news-to-video当前Editorial方案，说明主体位置和占比、前中后景、视角、景别、光线、色彩与风格。图像接口尺寸由实际支持决定。
- 保护区域：按当前制作镜头保留主体完整与底部字幕留白，不沿用旧竖屏坐标；不烘焙文字/数字/Logo。
- image_prompt：一段可直接使用的完整提示词，涵盖上述主体、环境和构图。
- negative_prompt：针对本图排除乱码、虚构界面/品牌/代码、错误权限/连接、拥挤遮挡、新闻现场误导等。
- 真实性：标“生成概念示意”或“写实生成示意”；参考链接（如有）、已核实外观及不能推断的细节。生成图不证明上线、用户规模或安全结论。
- 复用：S01/S03；不另生成同义图。准确产品界面缺素材时列缺口，改用通用示意或主题文字。

## 制作交接

- 默认交付基数：本期一份剧本 → 多个内容板块 → 一个制作项目 → 一个MP4；板块标题不是拆片指令。若用户明确拆片，列出具体集数与映射。
- 主题视觉、逐幕asset_id复用、读音/缩写、语义拆分和需要保留的限制。
- 本次交付状态为剧本，尚未生图/配音/渲染；分幕时长为规划，字幕时间应以实测配音重建。
- 仅用户明确要求实际图片或成片时交接news-to-video，不在本模板固定音色、音乐及项目JSON字段。
- 文字模式不输出以上制作字段，改为准确标题和自然段简报。

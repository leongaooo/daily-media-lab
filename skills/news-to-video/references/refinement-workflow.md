# 从短段精炼到可复用制作能力

## 先辨认本次授权

已有成片的精炼先定位问题，再做有代表性的短段对照。约20—30秒只是常见可比较窗口，不是时长配额；选择完整语义，保留母版、原干声、来源、失败记录与旧回执。

用户说“固化成果”“落实精炼成果”时结合上下文判断；无法确定是否继续制作时先对齐范围。用户明确“不需要制作整片”后，只做获授权的流程、组件、检查和资产整理，不启动整片、TTS、付费生图或平台发布。已确认改动在本批授权内继续完成，不重复询问。

## 一次审查区分五类证据

1. 技术：完整解码、画幅／帧数、音频身份、字幕连续性。
2. 图像：实际查看渲染图及状态变化前后，检查来源、主体、文字、保护区。
3. 连续声画：完整时序下的可理解性、节奏、承接与注意焦点。
4. 听觉：读法、吐字、停顿、尾音，耳机与普通扬声器各自的实际结果。
5. 用户反馈：原话、对应版本、范围与后续决定。

工具只有离散图像或数值时，继续可做检查并明确缺失层。播放器结束、未静音、识别结果、波形、峰值或自评分都不替代第三／四类证据。一般赞许可以登记当前样片方向获认可，不能推断跨设备试听、每个声音细项或跨题材风格已通过；旧回执保留历史状态，新增认可记录关联版本哈希。

## 素材丰富感来自不同内容角色

按当期理解目标组合原始证据、身份与使用条件合适的对象／行业资料、原创机制、实际检查项。每种素材应提供新信息：原页证明报道归属，专业对象帮助认物，动作解释变化，检查项帮助行动。不是每段都要四种素材，也不按镜头数、图片数或动画数验收。

获取网页／附件后检查原文件、页码、日期、上下文与使用条件，保留URL和内容哈希。重排摘述卡不能标成原页截图。行业资料标明通用身份；生成／原创图解不暗示真实现场、实测规模、已部署或已达标。没有匹配素材时用准确摘述或机制图，不插入无关实拍凑丰富度。

## 作者字段必须进入实际显示组件

旧图解项目以以下字段为权威；旧别名用于兼容已交付工程：

| 权威字段 | 兼容别名 | 行为 |
| --- | --- | --- |
| `editorial_nodes` | `nodes` | 透传全部节点；两份同时存在且不同则拒绝，避免选错事实 |
| `data_source` | `source` | 权威字段优先；不同时将差异写入生成载荷的 `field_mapping_notes` |
| `editorial_summary` | `summary` | 权威字段优先；差异同样可追溯 |

空`comparison`、空`evidence_board`和空shot覆盖在声音／渲染前拒绝；对照恰好两项，检查板一至四项。检查板始终显示全部有效条目，focus只强调相应项。两项互补标准、独立方案不自动标成变化前／变化后：用`comparison_labels`显式写两项角色；未提供时只用中性“对照A／B”。完整Blender镜头仍按自己的清单验收，不继承旧节点数量。

检查作者输入、生成`src/data.json`和显示组件三处，不能只看制作计划。按语义事件确认焦点、对象动作和结果确有消费者；单条`motion_plan: sequence`不表示实现了多段动作。标题、图内标签、来源和字幕各有职责，避免同句长标题重复占据主画面。

## 冻结干声与语义字幕

已有最终口播沿用[冻结入口](blender-handoff.md#冻结最终口播)，播放倍率1.0。只改画面／字幕不触发TTS、再变速、再降噪、补间隔或分段重拼。改稿必须另立声音版本，不能覆盖旧音轨。

检查长字幕时结合发音、语义单位、专有名词、日期数字、图内负担和实际字形，不凭字符数判失败。切分后的字词与顺序必须能拼回锁定稿。本地ASR词级时间是机器估计，保留原文并记录识别差异；不是强制对齐或人耳确认，不能按字数均分后冒称实测。用绝对时点统一帧化，末帧覆盖尾音，短窗口与完整母版身份分开。

建立审查窗口可用只读母版提取器：

```powershell
python scripts/review_window.py --source final-vocal.wav --start-sample 24000 --end-sample 504000 --output review/window.wav
```

只接受有效的单声道原声与整数样本区间`[start,end)`，保持原采样率和解码PCM，不做声音处理。输出为独立WAV及`window.wav.identity.json`，记录母版／窗口SHA256、采样身份、区间与偏移。已有目标或回执、源与目标同一路径、异常音频均拒绝。窗口文件字节不等于完整母版字节；DOUBLE窗口在后续读取链的精度仍按实际消费者核验。

## 资源压力下的有界执行

本次21秒样片在Windows资源压力下使用单任务、顺序编码与有界线程完成；准确的原生退出原因未证实，不把所有`write EOF`归为同一原因。需要时在项目内显式配置：

```json
{
  "editorial": {
    "render": {
      "concurrency": 1,
      "parallel_encoding": false,
      "ffmpeg_threads": 2,
      "node_heap_mb": 384
    }
  }
}
```

这些值是本次恢复起点，不是所有机器的固定默认。省略时保留原默认；未知字段、布尔值冒充整数或无效范围预检拒绝。配置仅作用于渲染子进程与本次生成工程，不改系统设置或共享模板，不结束其他任务。生产TEMP/TMP仍按[作业根规范](local-runtime.md#作业根与暂存)设置，保护母版与必要缓存。

## 复用与回归

资产登记可复用角色、源／使用条件、原始内容身份、实际查看状态、适用题材和禁止暗示。用户认可的本期配色、机架、排布不变成所有栏目固定模板；私声及未授权文档图片不进入公开示例。公开工程使用合成内容验证相同机制。

本次回归应覆盖字段透传、空内容／冲突拒绝、全部检查项进入真实显示组件、中性／显式对照标签、冻结窗口精确样本、资源参数消费者与用户明确不制作的范围。区分脚本检查、组件输出、制作实战、连续观看、试听和用户认可。通过后停止扩张，不为固化成果重新制作整片。

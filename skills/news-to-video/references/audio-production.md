# B 版唯一声音与免费音乐池

2026-11-04 用户选定 B 版男声，并明确废弃此前配音。本规则覆盖旧默认，不修改技能的触发范围。

## 唯一声音

- 项目默认 `voice: {"id":"b-male-v1","speed":1.15}`，省略也相同。B 版是分离后人声参考驱动的本地 Qwen3-TTS 1.7B Base 推理，不是训练独立模型。
- 声音策略位于 `assets/voice-policy.json`，固定参考音频/文字哈希及已认可的采样设置。运行时私有参考保存在技能外，不能把客户声音打包进通用技能。
- 渲染解释器和 Qwen 解释器分离。运行适配器中的 `tts_python`、`voice_profile` 指向本地环境及私有配置；模型版本与权重哈希由 `assets/runtime-lock.json` 固定。
- 旧 Kokoro/A 版/SAPI/其他本地声音/云端都不是备用选项。旧项目或运行环境不匹配时明确失败，修复 B 后端；不能以“保证出片”为由换声。
- 相同文字、参考、模型和采样配置复用干声缓存。旧引擎缓存不参与新键。原生干声为1.0，默认用FFmpeg atempo进行1.15倍保留音高变速；只改语速复用原生缓存，不重新合成，不改变参考或采样设置。变速缓存按原文件哈希、倍率与版本隔离；显式1.0复现原速，接受0.5–2.0有限数值，拒绝布尔值和非数值。字幕按变速后实测长度重建，音乐原速。长稿每批最多8段，在独立进程间释放模型与分配器；每段落盘后即可续用，失败重跑不重做已完成片段。
- 历史视频、原始参考和回滚备份保留作记录，不能当作新的候选声音。音色学习的本次参考未上传。

## 免费成品音乐

音乐池位于 `assets/music-pool/manifest.json`，当前保留 3 首 Kevin MacLeod 官方曲目：`voice-over-under`、`tech-live`、`inspired`。许可证为 CC BY 4.0；来源、授权页面、原始音频 SHA256 均保留。免费包含商业使用但要求公开署名，不等于无条件使用。

```json
{
  "voice": {"id":"b-male-v1","speed":1.15},
  "music": {"mode":"pool","style":"business","relative_db":-19.0,"duck_db":2}
}
```

- `style`: business/news/documentary。未指定 `track_id` 时，强制从 `voice-over-under`、`tech-live`、`inspired` 三首中随机选择；指定 `track_id` 时固定使用该曲目。默认 `relative_db=-19.0`。
- `mode: off` 明确关闭音乐。缺曲目、无法解码、授权字段缺失或文件哈希不符时停止，不能回退程序短音、随机下载或无声冒称正常。
- 伴奏保留原速和立体声；相对实际语音活跃段 RMS 配平，默认低19dB，人声期间额外压低2dB；根据20ms实际PCM能量高于-36dBFS检测讲话，再保留半秒停顿并平滑避让，不把整段文件视为讲话。混音记录目标音乐RMS和实际音乐RMS，避免把绝对满幅增益误当作相对人声音量。轻度高通/低中频均衡为男声留空间，入片淡入、结束淡出，超长时做循环接缝。
- 这里使用 RMS，不是 LUFS；峰值保护也不等于真峰值或平台响度认证。必要时针对具体平台另测响度，最后以手机和耳机试听判断清晰度。
- 渲染生成 `音乐署名.txt`，并写入 `production-plan.md`。发布时把其中作者、曲名、来源、授权及改动说明放到实际发布文案或片尾，只留在本地工程不满足署名要求。
- 音乐风格来自作者说明与编辑选择，完整解码不代表人耳听感已经认可。

## 旧项目迁移

旧字段 `voice.id=zm_010`、`music.gain`、`music.tempo_multiplier` 已停用。先显式运行：

```powershell
& $runtime.python "<skill>/scripts/migrate_audio.py" "<project.json>"
```

脚本在源项目同目录保留 `*.before-b-voice.json`，仅改 voice/music，并输出 `*.audio-migration.json`。旧 gain=0 保持显式静音，其他旧短音配置迁移到默认音乐池；口播、分幕、画面和来源不变。声音变更后必须重新生成实测时间线，不可沿用旧字幕时长。

同一 B 项目仅改音乐时使用原输出目录：干声与画面缓存命中后只重混封装。验证 `validation.json` 中的 voice、music_mode、track_id、picture_stream_reused，并检查整片解码、字幕覆盖与峰值。

## 已认可轻度降噪默认（2026-11-05）

用户已试听并选择轻度降噪。所有B配音先按项目倍率变速，再执行 `afftdn=nr=8:nf=-35:tn=0:gs=6`，默认1.15倍不变；不处理背景音乐。24kHz补600样本尾部并移除600样本处理延迟，输出长度严格等于输入，保留尾音；按20ms/-36dBFS原声活动帧匹配RMS，统一限峰0.94，不裁切内部停顿。低能量或静音片段不放大。

原始参考、固定模型/采样及原生合成缓存不改，不需重新合成。降噪缓存由变速后文件哈希、滤波参数与版本隔离；失败不回退未经处理原声，删除未完成副本。验证报告model_sha256.cleanup记录实际处理。仅设speed=1.0表示原速，仍执行默认轻度降噪；未经降噪原声保留在缓存。更改处理默认后使用新缓存和时间线，不复用旧画面流；只改音乐仍可复用当前处理后声音与画面。

轻度降噪以减轻细碎底噪为目标，不宣称完全消除混响或所有合成伪影；人耳效果以用户已试听的候选为依据，技术检查不替代每次成片试听。历史交付不自动重制。

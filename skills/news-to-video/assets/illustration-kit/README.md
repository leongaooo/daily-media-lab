# 液冷解说素材

两件透明 SVG 共用 530×620 视窗。CDU 正面通过控制屏、泵和格栅区分设备，机柜通过导轨和服务器抽屉保留辨识度。两者都是通用原创示意。许可、SHA‑256 和端口锚点见 [素材清单](asset-manifest.json)。

## 按当期证据组景

1. 依据当期来源先确定要解释的关系、设备身份及状态边界。通用示意适合解释供回液或设备分工。报道具体机型、连管或部署状态时，使用已核验资料对照形态、拓扑与标注。
2. 将两件设备放入同一场景。按清单的 SVG 视窗坐标和画面实际缩放计算连线锚点。中性虚线表示路径，进入实际语义时段后再显示方向箭头、连续流动和状态标签，配色之外保留明确的线型、文字和方向。计划状态使用符合证据的措辞。数据、日期和限制条件由当期证据填入。
3. 用支持渐变和路径的本地后端生成透明 PNG。先按 1920×1080 构图，保持 y904–1080 字幕位置，再缩到 326px 复核主体、线型、方向及实际标注。静态说明可进入 Remotion hero 图片槽。需要动作时，用逐帧对象舞台或独立合成，按实际整数帧、冻结口播和代表帧核对时序。
4. 日常只维护 SVG、许可和清单。场景布局、路线、短段、透明 PNG 和预览由当期任务生成。清单中带有形态与锚点，可用于重新构图。

现有 Remotion hero 在素材旁保留原生标题区，326px 预览中的图内次级字偏小。若需要设备和管线成为主体，优先用满幅合成，让画面大小匹配当期资料密度。
